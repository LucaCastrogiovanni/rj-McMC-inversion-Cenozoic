# rj-McMC-inversion-Cenozoic
The repository includes the rj-McMC algorithm used for the inversion of pCO2 proxy-data from the Cenozoic and estimated source and sink CO2 fluxe time series. 


Plase Note: After the rj-McMC inversion, reconstructed time series of Gamma (i.e., Source) and Beta are named mean001.002.out and mean001.002.out, respectively. In the code I provide also a Sink.txt file which was calculated as Beta*Temperature.
